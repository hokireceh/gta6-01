VICE BAY — game crime open-world 2D top-down yang jalan sepenuhnya offline di browser desktop. Curi mobil, kabur dari polisi, rampok toko, dan selesaikan 5 misi cerita sampai jadi Raja Teluk — lalu lanjut free roam.

Yang ada di dalam game:

- Kota Vice Bay 2600×1800 dengan jalan, trotoar, gedung, pantai, dan dermaga
- Jalan kaki (WASD + Shift sprint), masuk/keluar mobil (E), nyetir, curi mobil (carjack)
- Traffic yang mengikuti jalan dan belok di persimpangan, pejalan kaki yang kabur
- Wanted 0–5 bintang: mobil polisi dan polisi jalan kaki mengejar, menembak, dan BUSTED kalau menyentuhmu
- Combat pistol (klik / F), tabrak dengan mobil, mobil bisa meledak, health pickup
- 5 misi cerita berantai dengan payout sampai total $3.350, lalu WIN + free roam
- HUD (HP, uang, bintang, objektif + jarak), minimap (M), panah penunjuk misi, pause (P/Esc)
- Save / continue otomatis via localStorage tiap misi selesai

## Run it

```sh
node serve.ts
# buka http://localhost:8080
```
