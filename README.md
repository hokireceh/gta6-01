VICE BAY — a 2D top-down open-world crime game that runs fully offline in a desktop browser. Walk the streets, steal cars, outrun the police, rob a shop, survive a 90-second getaway at wanted level 3, and steal the gold car to the penthouse to win. Five chained missions, a wanted system with police chases and shootouts, traffic and pedestrians that react to you, a minimap, and automatic save/continue.

## Run it

```sh
node main.ts
```

Then open http://localhost:4173 — no build step, no dependencies, no network needed. `/health` answers `{"ok": true}`.
