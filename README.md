**VICE BAY** — a 2D top-down open-world crime game that runs fully offline in your desktop browser. Walk the neon streets of Vice Bay, steal cars, outrun the police, and climb from small-time hustler to King of the Bay across 5 chained story missions.

- On-foot and driving gameplay: walk, sprint, steal any parked or driven car, drive with traffic
- Living city: traffic cars that follow the roads, pedestrians on the sidewalks, a day-to-dusk neon look
- Wanted system: 0–5 stars, police cars and foot cops chase you, lose them to cool off — or fight back
- Combat: pistol firefights, car ramming, health and ammo pickups
- 5 story missions: first wheels, a hot pickup, losing the heat, a timed getaway, and the final golden-car heist
- HUD + minimap, mission tracker, start screen, pause, and save/continue via localStorage
- No build step, no external assets, no network needed — just Node.js 22.18+ and a desktop browser

## Controls

| Keys | Action |
| --- | --- |
| W A S D / arrows | Move on foot / drive (W accelerate, S brake/reverse, A D steer) |
| Shift | Sprint on foot |
| E | Enter / exit car, pick up mission items |
| Mouse aim + click / F | Shoot pistol |
| P or Esc | Pause |
| M | Toggle minimap zoom |

## Run it

```sh
node main.ts
```

Then open http://localhost:8080 in your desktop browser. Set a different port with `PORT=3000 node main.ts`.
